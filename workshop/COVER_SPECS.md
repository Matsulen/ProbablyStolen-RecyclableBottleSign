# 模组封面规格

记录《酒瓶水瓶回收灯牌》封面用到的全部规格，以后做其他模组的封面可以照这套来。

## 各平台的画幅

| 平台 | 比例 | 渲染尺寸 | 交付文件 | 说明 |
|---|---|---|---|---|
| Steam 创意工坊 | 16:9 | 640×360 | GIF | 主预览图上限 1 MB。物品详情页按 16:9 显示 |
| GitHub README | 16:9 | 640×360 | GIF | 与创意工坊共用一个文件 |
| 小红书 | 3:4 竖版 | 1080×1440 | PNG、MP4、GIF 540×720 | 图文笔记用 PNG；要动效用 MP4 发视频笔记 |
| bilibili | 4:3 横版 | 1440×1080 | PNG、MP4、GIF 720×540 | |
| 游戏内模组菜单 | 1:1 | 288×288 | `preview.png` | 放在模组文件夹根目录，小于 1 MB |

Steam 没有公开的创意工坊封面尺寸文档，16:9 和 1 MB 来自社区帖子和游戏自带的模组指南，以上传界面的预览框为准。

## 设计原则

目标：在一排模组封面的小缩略图里也能一眼被看到。

1. **只留一个主体。** 模组的核心贴图放大后居中，其余元素都为它让路。
2. **亮色底。** 多数模组封面是偏暗的游戏截图，高饱和的亮色底本身就能跳出来。
3. **深色圆盘托住主体。** 主体放在深色圆盘里，外加一圈浅色描边，和亮底形成最强的明暗对比。
4. **配角最多两个。** 一左一右夹住主体。再多，缩小后只是一排碎点。
5. **标题四个字以内。** 写玩家能得到什么，不写模组全名。创意工坊会在封面旁边另外显示标题。
6. **缩到 200 像素宽检查一次。** 主体和标题都要能认出来。
7. **像素贴图只做整数倍放大**，用最近邻插值，不要平滑。

## 配色

| 用途 | 色值 |
|---|---|
| 底色（放射条纹暗部） | `#2fb24c` |
| 放射条纹亮部 | `#8cf06a` |
| 圆盘外圈光晕 | `#14301f` |
| 圆盘描边、标题文字 | `#f4f1dc` |
| 圆盘底、标题描边 | `#17131f` |
| 圆盘内发光 | `#1f3a2a` |
| 主体熄灭时的遮罩 | `#0e0c16`，不透明度约 69% |

换模组时把两种绿色换成该模组的主题色即可，其余深色和奶白色可以沿用。

## 版式

数值以 16:9 的 640×360 为基准，其他画幅等比例放大后微调。

| 元素 | 16:9（640×360） | 4:3（1440×1080） | 3:4（1080×1440） |
|---|---|---|---|
| 圆盘圆心 | (184, 180) | (452, 540) | (540, 560) |
| 外圈光晕半径 | 166 加脉动 | 412 加脉动 | 456 加脉动 |
| 浅色描边半径 | 158 | 392 | 434 |
| 深色圆盘半径 | 150 | 372 | 412 |
| 内发光半径 | 138 | 344 | 380 |
| 主体贴图（32×32）放大倍数 | 6 倍，192 像素 | 15 倍，480 像素 | 17 倍，544 像素 |
| 配角贴图放大倍数 | 3 倍 | 7 倍 | 8 倍 |
| 标题排法 | 右侧，上下两行，每行两字 | 右侧，上下两行，每行两字 | 底部，一行四字 |
| 标题字号 | 120 | 246 | 236 |
| 标题描边粗细 | 18 | 38 | 40 |

- 标题字体：微软雅黑粗体，浅色填充加深色描边，描边用圆角连接。
- 放射条纹：12 条亮色扇形，每条 15 度，间隔 15 度，圆心与圆盘圆心重合。
- 配角贴图放在圆盘左右两侧，压住圆盘边缘。

## 动画

| 项目 | 数值 |
|---|---|
| 帧率 | 每秒 12 帧 |
| 循环长度 | 24 帧，2 秒，首尾无缝 |
| 放射条纹 | 一个循环转 30 度，正好一个条纹周期 |
| 外圈光晕 | 半径按正弦脉动一次 |
| 配角 | 左右交替弹跳，各跳两次，高度约为画面高度的 5% |
| 霓虹闪灭 | 第 19、21 帧主体熄灭 |

每一帧都是完整的封面，截取任意一帧都能当静态图用。

## 导出

用 ffmpeg 把渲染好的帧序列编码：

```
# GIF：先生成调色板，不加抖动，体积最小
ffmpeg -framerate 12 -i f%03d.png -filter_complex "scale=宽:高:flags=area,split[a][b];[a]palettegen=max_colors=64:stats_mode=full[p];[b][p]paletteuse=dither=none:diff_mode=rectangle" -loop 0 out.gif

# MP4：循环 4 遍，共 8 秒
ffmpeg -stream_loop 3 -framerate 12 -i f%03d.png -c:v libx264 -crf 16 -pix_fmt yuv420p -r 24 -movflags +faststart out.mp4
```

本模组各文件的实际体积：16:9 的 GIF 161 KB，3:4 的 GIF 280 KB，4:3 的 GIF 285 KB，MP4 都在 1 MB 以内。

## 说明用动图

模组描述里演示功能的动图是另一套规格：

- 宽 560 到 600 像素，16:9，每秒 8 到 10 帧，64 色，不加抖动。
- 每张 3.5 到 7.5 秒，只讲一个功能点。
- 单张压到 1.85 MB 以下，创意工坊的上限是 2 MB。
